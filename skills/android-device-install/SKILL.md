# Android Device Install

Builds with Gradle and installs via `adb`. Covers all Android-based targets: phones, tablets, emulators, Android TV, Fire TV, Google TV.

## Full process (first time on a new device)

### Option A — EAS cloud (no local SDK needed, recommended)

1. `~/.claude/scripts/rn-device-install android --eas`
2. EAS builds the APK in the cloud and shows a download link
3. Open the link on the Android device
4. Allow "Install from unknown sources" if prompted:
   Settings → Security → Install unknown apps → allow for your browser
5. Tap Install

### Option B — Local build via USB (needs Android SDK + adb)

1. **Enable USB Debugging:** Settings → Developer Options → USB Debugging → On
   *(Developer Options: Settings → About Phone → tap "Build number" 7 times)*
2. **Prerequisites check:** `adb devices` — device should show as `authorized`
3. **Configure:** if `android/gradlew` is missing:
   `npx expo prebuild --platform android`
   The script detects this and prints instructions automatically.
4. **Build + install:** `~/.claude/scripts/rn-device-install android`

## Script

```bash
~/.claude/scripts/platform/rn-android.sh [options]
# or via entry point:
~/.claude/scripts/rn-device-install android [options]
```

## Options

| Flag | Default | Notes |
|------|---------|-------|
| `--config release\|debug` | `release` | Gradle configuration |
| `--flavor NAME` | none | Gradle product flavor (e.g. `fireTV`, `androidTv`) |
| `--target device\|emulator\|auto` | `auto` | Prefers real device over emulator |
| `--device SERIAL` | auto | Specific `adb` serial |
| `--avd NAME` | — | AVD to launch (implies `--emulator`) |
| `--no-install` | off | Build only, skip `adb install` |
| `--emulator` | — | Shorthand for `--target emulator` |
| `--verbose` | off | `set -x` |

## TV platform flavors

Android TV, Fire TV, and Google TV are all standard Android and appear identically to `adb`. The only difference is the Gradle build flavor and the target device's model.

| Target | Gradle flavor example | Notes |
|--------|----------------------|-------|
| Android TV | `--flavor androidTv` | Samsung, Sony, Nvidia Shield |
| Fire TV | `--flavor fireTV` | Amazon Fire TV Stick, Cube |
| Google TV | `--flavor googleTv` | Chromecast w/ Google TV |

Configure flavors in `android/app/build.gradle`:
```groovy
android {
  flavorDimensions "device"
  productFlavors {
    mobile    { dimension "device" }
    androidTv { dimension "device" }
    fireTV    { dimension "device" }
    googleTv  { dimension "device" }
  }
}
```

## What the script does

1. Detects connected device/emulator via `adb devices`
2. Starts AVD if `--avd` specified and emulator not yet running
3. Kills Metro on port 8081
4. Runs `./gradlew assemble<Flavor><Config>` (e.g. `assembleFireTVRelease`)
5. Locates APK (handles flavor subdirectories automatically)
6. Installs via `adb -s <SERIAL> install -r`

## Gotchas

| Symptom | Cause | Fix |
|---------|-------|-----|
| No device found | USB debugging off | Settings → Developer Options → USB Debugging → enable |
| Device shows `unauthorized` | ADB prompt not accepted | Unlock phone, accept "Allow USB debugging" popup |
| Device shows `offline` | USB cable or driver issue | Try different USB port/cable; `adb kill-server && adb start-server` |
| APK not found | Wrong config/flavor name | `ls android/app/build/outputs/apk/` to find actual path |
| Gradle build fails | Clean state needed | `cd android && ./gradlew clean` then retry |
| App crashes on launch | Release keystore not configured | Configure signing in `android/app/build.gradle` |
| Emulator not found | AVD not created | `avdmanager create avd -n MyAVD -k "system-images;android-34;google_apis;x86_64"` |
| `INSTALL_FAILED_OLDER_SDK` | APK min SDK higher than device | Build Debug config or use a newer device/emulator |

## Framework detection

Script auto-detects Expo vs bare RN via `package.json`. Both use Gradle identically — for Expo the JS bundle is generated by the Gradle build phase.

## Composable usage

```bash
source ~/.claude/scripts/platform/rn-android.sh

# Fire TV specific build + install
RN_ANDROID_FLAVOR=fireTV RN_ANDROID_CONFIG=release rn_android_build_and_install

# Emulator with specific AVD
RN_ANDROID_TARGET=emulator RN_ANDROID_AVD=Pixel_9_API_35 rn_android_build_and_install

# Build only (CI)
RN_ANDROID_NO_INSTALL=1 rn_android_build_and_install
```

## Manual build (bypass script)

```bash
DEVICE=$(adb devices | grep -v "List\|offline\|^$" | grep "device$" | head -1 | awk '{print $1}')
cd android && ./gradlew assembleRelease --no-daemon
adb -s "$DEVICE" install -r app/build/outputs/apk/release/app-release.apk
```
